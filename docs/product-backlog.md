# K-학당 제품 백로그

이 문서는 K-학당을 교육용 게임이자 Google Play 출시 상품으로 완성하기 위한 작업 목록이다.

## 1. 교육 콘텐츠

- 속담, 사자성어, 역사, 예절, 문해력 콘텐츠 품질 검수
- 난이도별 문제 묶음 구성
- 오답 해설 강화
- 학습 목표와 보상 연결
- 반복 학습, 복습, 약점 보완 흐름 추가
- 초등/청소년/외국인 학습자 등 대상 사용자별 콘텐츠 톤 정리

## 2. 게임성 업그레이드

- 일일 미션과 출석 보상 밸런스 조정
- 하트, 코인, XP, 레벨 보상 경제 점검
- 스테이지 진행감 강화
- 미니게임별 성공/실패 피드백 개선
- 연속 정답, 콤보, 칭호, 업적 보상 강화
- 학습과 미니게임이 따로 놀지 않도록 연결 구조 개선

## 3. UI/UX 개선

- 모바일 첫 화면의 핵심 행동을 명확하게 정리
- 퀴즈 화면의 가독성, 버튼 크기, 피드백 속도 개선
- 학당 허브의 카테고리별 진도와 약점 표시 강화
- 프로필 화면에서 성장, 업적, 복습 항목을 더 쉽게 파악하게 개선
- 작은 화면에서 텍스트 겹침, 버튼 넘침, 스크롤 피로 점검
- 출시 전 주요 화면 스크린샷 품질 개선

## 4. 이미지와 시각 자산

- Google Play 512x512 앱 아이콘 제작
- 1024x500 피처 그래픽 제작
- 스토어용 휴대폰 스크린샷 구성
- 캐릭터 기본 이미지와 보상 이미지 품질 개선
- 학당별 대표 이미지 또는 배경 분위기 제작
- 보상형 광고, 프리미엄 상품, 이벤트 배너용 이미지 후보 제작

## 5. 수익화

- 보상형 광고 위치 후보: 하트 회복, 힌트, 추가 보상
- 인앱결제 후보: 광고 제거, 하트 패키지, 프리미엄 학습팩, 꾸미기 아이템
- 무료 사용자 경험을 해치지 않는 제한선 설계
- 어린이 대상 가능성을 고려한 광고/결제 정책 검토
- 개인정보처리방침, 이용약관, 데이터 수집 범위 정리

## 6. 출시 준비

- Android 패키징 방식 확정
- 앱 서명, 버전 관리, 릴리즈 노트 준비
- Play Console 등록 정보 작성
- 개인정보 및 데이터 보안 섹션 준비
- 내부 테스트, 비공개 테스트, 프로덕션 출시 단계 계획
- 빌드, 린트, 브라우저 검증 루틴 안정화

## 7. Codex 자동 루프가 할 일

- 매번 빌드 또는 린트 상태를 확인한다.
- Claude Code가 구현한 기능을 출시 관점에서 검증한다.
- 작은 안정성 수정, 메타데이터 수정, 문서 갱신을 직접 수행한다.
- 큰 기능 개발이나 콘텐츠 대량 제작은 Claude Code 또는 사용자 지시 작업으로 정리한다.
- 이미지 제작이 필요한 경우 목적, 크기, 스타일, 사용 위치를 먼저 명확히 정의한다.

## 8. 제품 전략 우선순위

- 최우선: 교육 신뢰도. 문제 난이도, 학습 목표, 오답 해설 품질을 체계화한다.
- 두 번째: 지속성. 일일/주간/월간 반복 플레이 이유를 만든다.
- 세 번째: UI. 홈의 핵심 행동을 줄이고 학당 허브를 추천 학습 중심으로 강화한다.
- 네 번째: 수익화. 보상형 광고와 광고 제거 상품부터 작게 검증한다.
- 다섯 번째: 정책 안정성. 데이터 안전, 개인정보, 어린이/가족 대상 가능성을 먼저 정리한다.

세부 분석은 `docs/product-strategy-audit.md`를 기준으로 한다.
