# K-학당 협업 역할 분담

## Codex 역할

Codex는 출시 운영, 품질 검증, 자동화 담당이다.

- 프로젝트 상태를 주기적으로 진단한다.
- `build`, `lint`, 테스트, 브라우저 검증을 실행한다.
- Claude Code가 만든 변경을 리뷰하고 작은 결함을 직접 고친다.
- Google Play 출시 체크리스트와 수익화 준비 항목을 관리한다.
- 자동 루프에서 다음으로 가장 출시 가치가 큰 작업을 고른다.
- 큰 기능보다 안정성, 검증, 문서화, 출시 준비를 우선한다.

## Claude Code 역할

Claude Code는 기능 개발과 콘텐츠 구현 담당이다.

- 게임 기능, 화면, 미니게임, 학습 흐름을 구현한다.
- 퀴즈 데이터와 교육 콘텐츠를 확장한다.
- 캐릭터, 보상, 출석, 미션 같은 플레이 경험을 개선한다.
- 실험적인 프로토타입을 빠르게 만든다.
- 사용자가 직접 지시한 기능 구현을 우선한다.

## 협업 흐름

1. Claude Code가 기능이나 콘텐츠를 만든다.
2. Codex가 빌드, 린트, 테스트, 화면 검증을 실행한다.
3. Codex가 결함을 작은 단위로 고치거나 Claude Code에게 넘길 작업으로 정리한다.
4. Codex가 출시 준비 문서와 다음 우선순위를 갱신한다.
5. 사용자는 제품 방향, 수익화 방식, 출시 판단을 결정한다.

## 현재 원칙

- Claude Code는 개발 엔진이다.
- Codex는 검증, 자동화, 출시 운영 두뇌다.
- 둘 다 같은 목표는 하나다: K-학당을 Google Play에 출시하고 수익화 가능한 교육 게임으로 완성한다.
