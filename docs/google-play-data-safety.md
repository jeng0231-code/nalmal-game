# K-학당 Google Play 데이터 안전 초안

작성일: 2026-05-26

이 문서는 현재 기본 출시 설정을 기준으로 Google Play Console의 데이터 안전 섹션에 입력할 초안이다. 법률 검토 문서가 아니라 운영용 초안이며, 실제 출시 전 SDK 구성과 정책 문구를 다시 확인해야 한다.

## 기준 설정

- 앱 기본 설정: `VITE_ENABLE_CLAUDE_FEATURES=false`
- 광고 SDK: 미연동
- 인앱결제 SDK: 미연동
- 분석 SDK: 미연동
- 서버 계정 시스템: 없음
- 학습 데이터 저장 위치: 로컬 저장소 중심

## 현재 제출 방향

- 현재 기본 출시 설정에서는 외부 서버로 전송되는 사용자 데이터가 없다고 보는 방향이 가장 안전하다.
- 사진 기반 AI 변환, AI 문제 생성 기능은 기본 비활성화 상태를 유지한다.
- 정식 출시 전에 AI 기능을 켜거나 광고·결제·분석 SDK를 추가하면 이 문서를 즉시 수정한다.

## Play Console 입력 초안

### 데이터 수집

- 개인 정보: 수집 안 함
- 금융 정보: 수집 안 함
- 위치: 수집 안 함
- 연락처: 수집 안 함
- 사진 및 동영상: 기본 출시 설정에서는 수집 안 함
- 오디오 파일: 수집 안 함
- 파일 및 문서: 수집 안 함
- 캘린더: 수집 안 함
- 앱 활동: 외부 수집 안 함
- 웹 탐색: 수집 안 함
- 앱 정보 및 성능: 수집 안 함
- 기기 또는 기타 식별자: 수집 안 함

### 데이터 공유

- 제3자와 공유하는 사용자 데이터: 없음

### 선택 항목 메모

- 이름 입력은 로컬 저장만 하며 서버 전송이 없다.
- 학습 기록, 캐릭터 설정, 사진 모드 데이터는 로컬 저장만 한다.
- 카메라 또는 사진 선택 기능은 기기 권한 사용 가능성이 있지만, 기본 출시 설정에서는 외부 전송을 동반하지 않는다.

## 리스크 메모

아래 조건이 생기면 현재 초안을 그대로 쓰면 안 된다.

- AI 기능을 다시 활성화하는 경우
- AdMob 등 광고 SDK를 붙이는 경우
- Google Play Billing 또는 외부 결제 관련 SDK를 붙이는 경우
- 분석 SDK를 붙이는 경우
- 서버 동기화, 로그인, 클라우드 저장 기능을 붙이는 경우

## 출시 직전 확인 항목

1. `.env`와 배포 환경에서 `VITE_ENABLE_CLAUDE_FEATURES=false` 유지 확인
2. 빌드 결과에서 AI 기능 노출 문구가 출시 준비 상태로 보이는지 확인
3. 개인정보처리방침 URL을 `public/privacy-policy.html` 배포 경로로 연결
4. Play Console 데이터 안전 답변과 실제 SDK 구성이 일치하는지 재검토
