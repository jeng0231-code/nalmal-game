K-학당 개인정보처리방침

K-학당은 한국어와 한국 문화 학습을 위한 교육용 게임입니다. 이 문서는 현재 코드 기준의 출시 준비용 개인정보처리방침 초안이며, 실제 출시 전에는 운영자 연락처와 최종 연동 SDK 기준으로 다시 갱신됩니다.

현재 기본 출시 설정에서는 AI 기능이 비활성화되어 있으며, 광고 SDK·결제 SDK·분석 SDK도 연동되어 있지 않습니다.
정식 출시 전에는 운영 문의 연락처, 실제 연동 SDK 목록, Google Play 게시 URL을 반드시 이 문서에 반영해야 합니다.

1. 수집하는 정보

K-학당은 회원가입이나 서버 계정을 요구하지 않습니다. 현재 기본 동작 기준으로 이름, 학습 진행 상태, 출석, 미션, 오답 노트, 캐릭터 설정 같은 학습 데이터는 사용자의 기기 또는 브라우저 저장소에만 저장됩니다.

  • 학습 기록: 레벨, 경험치, 코인, 하트, 학습 일자, 카테고리 통계
  • 캐릭터 정보: SVG 캐릭터 설정값, 선택한 꾸미기 정보
  • 기타 기록: 출석, 미션, 업적, 오답 노트, 튜토리얼 확인 여부

2. 선택 기능과 카메라·사진 사용

사용자가 직접 사진을 고르거나 촬영하는 기능을 사용할 경우, 해당 사진 데이터는 기기 내 저장 상태에 포함될 수 있습니다. 현재 기본 출시 설정에서는 사진 기반 AI 변환 기능이 비활성화되어 있어 외부 AI 서비스 전송은 일어나지 않도록 설계되어 있습니다.

3. 외부 전송과 제3자 처리

현재 기본 출시 설정에서는 학습 기록, 이름, 캐릭터 설정을 외부 서버로 전송하지 않습니다. 다만 향후 AI 기능을 별도 활성화할 경우 사용자가 선택한 사진 또는 AI 문제 생성 요청 정보가 외부 AI 서비스로 전송될 수 있으며, 그 경우 본 문서와 앱 안내 문구를 다시 갱신합니다.

4. 광고·결제·분석

현재 코드 기준으로 광고 SDK, 인앱결제 SDK, 분석 SDK는 연동되어 있지 않습니다. 향후 수익화 기능을 추가하면 수집 데이터 범위와 제3자 제공 항목을 본 문서에 다시 반영합니다.

5. 아동·가족 대상 원칙

K-학당은 어린이 또는 가족 대상 가능성을 고려해 보수적으로 운영합니다. 맞춤형 광고는 기본적으로 피하고, 과도한 결제 유도나 불필요한 개인정보 수집을 지양합니다.

6. 보관 및 삭제

현재 학습 데이터는 사용자의 기기 또는 브라우저 저장소에만 남습니다. 앱 삭제, 브라우저 저장소 초기화, 또는 향후 제공될 초기화 기능을 사용하면 해당 로컬 데이터는 삭제될 수 있습니다.

7. 문의 및 업데이트

현재 저장소 기준으로는 운영 문의 연락처가 아직 확정되지 않았습니다. 정식 출시 전에는 보호자와 사용자 문의를 받을 이메일 또는 웹 문의 경로를 여기에 명시해야 합니다. 정책이나 기능이 바뀌면 이 문서의 날짜와 내용을 함께 갱신합니다.
