# 축사 모니터 — 새 농장 설치 안내

CT2(Chore-Tronics) + C-Central 을 쓰는 농장에서, 온도·정압·음수량·설정·알람을
휴대폰/PC로 실시간으로 보는 프로그램입니다. **컨트롤러 정보를 읽기만** 하며(쓰기 없음),
**관리자 승인**을 받아야 사용할 수 있습니다.

---

## 준비물
- **C-Central 이 설치된 PC**(FCentral DB 가 있는 그 PC)에서 설치합니다.
- **Node.js** — 없으면 https://nodejs.org 에서 **LTS** 버전 설치 (한 번만).

## 설치 (더블클릭 한 번)
1. 받은 **`choretime` 폴더**를 바탕화면 등에 복사.
2. 폴더 안 **`설치시작.bat`** 더블클릭.
3. 창이 안내하는 대로:
   - SQL 인스턴스 이름 → 보통 그대로 **Enter** (기본 `localhost\FCENTRAL_EXPRESS`)
   - **이름 / 연락처 / 주소** 입력 (라이선스 서버 주소는 그대로 Enter)
4. 끝나면 서버가 켜지고, 화면엔 **"🔒 승인 대기 중 · 기기ID: ct-xxxx"** 가 나옵니다.
5. **관리자에게 그 기기ID를 알려주고 승인**을 요청하세요.
6. 승인되면 화면이 열립니다. (검은 서버 창은 **켜 둔 채로** 두세요.)

## 보는 방법
- **같은 건물 PC/폰**: 서버 창에 표시된 `http://(주소):8088`
- **밖에서(외부)**: 서버 창에 뜨는 **`🌐 외부 접속 주소: https://....trycloudflare.com`** 를 폰 브라우저에 입력.
  - 화면 우측 아래 **📱 버튼**을 누르면 그 주소가 **QR**로 나옵니다 — 폰 카메라로 찍어 접속.

## 자동 시작 (PC 켜면 자동 실행)
- 폴더 안 **`자동시작등록.bat`** 을 한 번 실행해두면, PC 를 켤 때마다 서버가 자동으로 켜집니다.
- **PC 절전 끄기** 권장: 설정 → 전원 → 화면/절전 "안 함", 최대 절전 "안 함". (밤사이 멈춤 방지)

---

## 관리자(제품 소유자)용
- 승인 보드: **https://ct-deploy.up.railway.app/admin**
  - 비밀번호 로그인 → 설치된 농장 목록 확인 → **승인 / 중지**.
  - 승인해야 그 농장 화면이 열리고, 중지하면 즉시 잠깁니다.

## 잘 안 될 때
- **DB 읽기 실패**: C-Central 이 있는 PC 에서 실행했는지, SQL 인스턴스 이름이 맞는지 확인.
- **화면이 계속 잠김**: 관리자 승인이 됐는지 확인(보드에서 "승인" 상태). 승인 후 최대 3분 내 자동 반영.
- **팬 번호/대수가 실제와 조금 다름**: 개별 팬 실시간은 컨트롤러 DB 특성상 ±오차가 있습니다.
  온도·정압·음수량·설정·알람은 정확합니다. (그래서 배포용은 개별 팬 "가동중" 표시를 빼고
  팬별 "설정온도"만 보여줍니다.)
